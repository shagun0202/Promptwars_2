# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-05-03

### Added
- **Core Platform:** Initial release of the SmartElect React 19 application.
- **AI Chat Assistant:** Fully integrated Gemini `gemini-flash-latest` with token-by-token streaming, strict rate limiting, and chat history.
- **Polling Station Finder:** Google Maps integration via Geocoding and Maps Embed APIs.
- **Video Learning Hub:** YouTube Data API v3 implementation with lazy loading.
- **Timeline Component:** Interactive 6-step election educational process.
- **Accessibility features:** High-contrast toggle, text sizing, dark mode, Google Cloud Text-to-Speech integration, and full WCAG 2.1 AA compliance.
- **Translation:** Full UI localization using Google Cloud Translation API.
- **Architecture:** Robust caching, error boundaries, typed session storage, sanitization, and strict TypeScript integration.
- **DevOps:** Google Cloud Run deployment configs via Docker, Nginx, and cloudbuild.yaml.
